### 工具管理

1. 不应在项目中留下临时脚本，应当定时清理。
2. 如果发现反复进行一个操作（或者类似的一整个操作，例如检查并上线）超过3次，就应该写工具。
3. 工具可以是临时工具（应当被删除和清理），也可以是正式工具，进入代码仓库被提交。按照情况决定。
4. IMPORTANT：写工具的目的是最小化想要操作的用户需要面对的操作，但是能在想要下钻的时候合适地展开。你往往不需要写冗长的复杂命令，合适的工具能让你执行的命令结构保持简单。


### CI/CD

1.应该尽量拆分并并行可并行的测试。
2.检查缓存是否命中

### Hooks

对于需要维护的任务，应该起单独的 Hooks 在合适的时候插入来保证维护。
